# Workflow Templates

These files are public-safe n8n workflow templates.

They intentionally do not include:

- n8n credential IDs or names
- OAuth tokens
- API keys
- private Google Sheet IDs
- private Google Drive file IDs
- production Gmail addresses
- live n8n workflow IDs
- webhook IDs

## Before Importing

Replace placeholders such as:

- `YOUR_WF_01_BUYER_DISCOVERY_WORKFLOW_ID`
- `YOUR_BUYER_DATABASE_SPREADSHEET_ID`
- `YOUR_BUYER_DATABASE_SHEET_NAME`
- `YOUR_COMPANY_PROFILE_FILE_ID`
- `YOUR_CATALOG_PRODUCT_FILE_ID`
- `YOUR_REPLY_TO_EMAIL`
- `YOUR_SENDER_NAME`

Then connect credentials inside n8n after importing.
